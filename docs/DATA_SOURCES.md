# Data Sources and Sharing Boundary

Last updated: 2026-08-09

Target public repository: `streaming-softmcc-drift`

## Synthetic Streams

The abrupt, gradual, recurring, stationary, and joint concept-calibration streams are generated by the scripts in `../code/`. They do not require external data.

## Public-Source-Derived Caches

The credit-card-fraud and IoTID20 experiments use prepared NPZ caches named:

- `creditcard_pi10.npz`
- `iotid20_compact.npz`

In the project evidence run, these caches are stored outside this replication
package under the SoftMCC Theory project data area. They are derived from public
sources cited in the manuscript.

The scripts resolve cache files by checking, in order, `STREAMING_SOFTMCC_DRIFT_DATA_DIR`, legacy `DRIFTMCC_DATA_DIR`, this package/project `data` folder if present, the sibling `SCI-SoftMCC_Theory/02_data` folder, and the legacy `SCI-s1e1-SoftMCC/02_data` folder. For a standalone GitHub clone, set `STREAMING_SOFTMCC_DRIFT_DATA_DIR` to the folder containing the two NPZ files.

## Source Links and Local Cache Building

Credit-card fraud source:

- Kaggle/MLG-ULB credit-card fraud dataset:
  `https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud`

IoTID20 sources:

- Official IoT Network Intrusion Dataset project page:
  `https://sites.google.com/view/iot-network-intrusion-dataset/home`
- Kaggle mirror:
  `https://www.kaggle.com/datasets/rohulaminlabid/iotid20-dataset`

The package includes `../code/real_cache_prep.py` so users can build private
local caches after obtaining the raw CSV files from the source pages.

Example private layout:

```text
<raw-dir>/creditcard.csv
<raw-dir>/IoTID20.csv
```

or:

```text
<raw-dir>/data/creditcard.csv
<raw-dir>/IoTID20/data/IoTID20.csv
```

Example commands:

```powershell
$env:SOFTMCC_RAW_DIR="C:\path\to\private\raw"
$env:STREAMING_SOFTMCC_DRIFT_DATA_DIR="C:\path\to\private\caches"
python -u code\real_cache_prep.py all
```

## What Is Not Included

Raw public data files and prepared real-data NPZ caches are not included in this package. The trace NPZ files generated from the current evidence run are included so the manuscript figures can be regenerated without rerunning all experiments. These trace files are study-generated result artifacts, not the raw feature matrices.

The following files must remain outside the public GitHub release under the
2026-06-23 source-governance decision:

- `creditcard.csv`
- `IoTID20.csv`
- `creditcard_pi10.npz`
- `creditcard_pi5.npz`
- `iotid20_compact.npz`

## Governance Decision

Evidence: the active-project raw CSV identities and hashes were recorded before
the 2026-08-09 retention cleanup, and the canonical run transcripts resolve
caches from a private/sibling data location. The duplicate raw CSV files are no
longer retained in the Syncthing tree. On 2026-08-09, one-byte range requests to
both Kaggle download APIs returned HTTP 206 with `application/zip`. IoTID20's
official source page grants academic research use and requests citation. The
credit-card-fraud source page exists, but this audit did not capture stable
license text that would justify raw redistribution.

Inference: local analysis and citation are supportable; unrestricted raw/cache
redistribution is not established for the public GitHub package.

Interpretation: the public `streaming-softmcc-drift` repository should provide
code, results, figures, trace artifacts, transcripts, and cache-building
instructions, while requiring users to obtain raw data from original sources and
build private caches locally.
