# streaming-softmcc-drift

Replication package for the manuscript:

**Windowed and Fading Soft Matthews Correlation Coefficient Estimators for Prequential Performance Monitoring under Concept Drift**

This folder is the submission-facing supplementary package and the local source
for the public repository `streaming-softmcc-drift`.

## Contents

- `code/`: active Python scripts used for Streaming SoftMCC, theory checks, drift analyses, figure generation, joint concept-calibration probes, and metric-family comparisons.
- `results/`: CSV, summary, and trace NPZ result artifacts copied from the project evidence folder. These are manuscript evidence files, not smoke-test outputs.
- `figures/`: current manuscript-facing PNG figures regenerated from the trace and summary artifacts.
- `docs/`: replication notes, data-source boundaries, result traceability notes, and canonical run transcripts.
- `data_sample/`: intentionally empty. Raw public datasets and prepared NPZ caches are not redistributed here.
- `requirements.txt`: exact package versions captured by the canonical evidence run.

## Data Boundary

Synthetic streams are generated by the scripts. Credit-card-fraud and IoTID20 runs depend on public-source-derived caches prepared outside this package. Raw data and prepared real-data caches are not included in the public package. Users should obtain the public source datasets and build private local caches with `code/real_cache_prep.py`; see `docs/DATA_SOURCES.md`.
